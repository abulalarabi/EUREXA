# EUREXA: End-User Reconfiguration of Environment with eXplainable Augmentation for Generative Fabrication

This repository is the official project site for our research paper on EUREXA.

## About

EUREXA is a novel approach that enables end-users to reconfigure their environment through explainable augmentation techniques designed for generative fabrication. Our system combines user-friendly interfaces with powerful AI-driven tools to make digital fabrication more accessible and understandable.
